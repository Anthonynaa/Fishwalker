Десериализация данных:
- Не делать прямого сравнения строк после чтения из csv, лучше задать значения enum'ом и конвертировать значения в константы
- Избегать операций со строками (e.g. сравнение), потому что они максимально неэффективные
- Для обработки использовать тип int

Реляционная модель - работа с базами данных идёт через двумерные таблицы (отношения)

- std::shared_ptr - не очень ему нравится, потому что может быть плох с точки зрения дизайна: обычно у каждого объекта должен быть свой 1 владелец для точного удаления, а shared pointer размазывает владение
- Хранение std::shared_ptr в std::vector - максимально неэффективная история (но может быть ок для наших размеров)

- Можно учесть в парсере, что если в кавычках точка с запятой (;), то считаться за разделением не будет

(!! Поищи Find из стандартной библиотеки - что-то может уже готовое подойти)
- Template для FindById в GameDatabase_Query для работы с любым типом данных:
namespace {

template<typename T>
const T* FindById(const std::vector<T>& vec, int id) {
  for (const auto& item : vec)
    if (item.id == id) return &item;
  return nullptr;
}

}

- В строках .csv использовать {value} на местах где будут значения - меньше хардкода
(Реализация может быть как собственная (FormatMult), так и уже имеющаяся(?) по стандарту)
